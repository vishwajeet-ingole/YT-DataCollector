# YouTube Data Collector

A Python-based YouTube data collection, analysis and audio extraction project.

## Features
- YouTube metadata collection
- Video metadata extraction
- License and privacy auditing
- Permission approval management
- Approved video downloading
- Audio extraction using FFmpeg
- Master dataset generation
- Excel reporting
- Automated quality checks

## Tech Stack
- Python
- Pandas
- OpenPyXL
- YouTube Data API
- yt-dlp
- FFmpeg
- Requests

## Installation

Create virtual environment:

python3 -m venv venv
source venv/bin/activate

Install dependencies:

pip install -r requirements.txt

## Configuration

Configure API credentials in your local .env file.

Never upload API keys or secrets to GitHub.

## Usage

Run the Python scripts from the scripts directory.

## Output

Generated datasets and reports are stored in output/.
